# Get started

Use this path to connect your first two machines.

## Choose an outcome

- **Try NetP2P**: create a network with `netp2p init network`, run one manager,
  and enroll a client.
- **Use a shared network**: an administrator creates groups, policy, and a setup
  key, then gives you the manager endpoint and a key.

## Prerequisites

- Two or more Linux or Windows machines.
- Administrator/root access on each enrolled machine.
- HTTPS access to the manager console or API endpoint.
- UDP 4001 and 4101 access for overlay transport and path discovery.
- A valid setup key from the administrator for shared networks.

## Path

1. [Create a network](create-network.md) if you are the first administrator.
2. [Join Linux](join-linux.md) or [join Windows](join-windows.md).
3. [Verify connectivity](first-connection.md) between two enrolled peers.

For production deployment and committee operations, use the self-hosting and
operations documentation.
